# Lumina ERP

Painel ERP Next.js da Lumina para gestão de insumos, ficha técnica, precificação, estoque, produção e pedidos de ateliê. Stack: Next.js, TypeScript, Tailwind, shadcn/ui, Zustand, PostgreSQL, Prisma ORM e Docker.

Para iniciar: `pnpm install` e `pnpm dev`.

Leia [ARCHITECTURE.md](ARCHITECTURE.md) antes de qualquer alteração estrutural, de convenção ou regra de negócio. Use exclusivamente pnpm.
