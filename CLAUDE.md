# Lumina ERP

Projeto Next.js de painel ERP. Use somente pnpm: `pnpm install`, `pnpm dev`, `pnpm lint`, `pnpm typecheck` e `pnpm build`.

Antes de editar, leia [ARCHITECTURE.md](ARCHITECTURE.md). Para UI, leia [docs/DESIGN.md](docs/DESIGN.md) e use os tokens semânticos de `src/app/globals.css`. Não use npm/yarn, barrel files, `any` explícito, cores arbitrárias ou lógica de negócio em UI.
